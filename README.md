# 험쮜 메이커 — STAGE:ZERO 론칭 대작전

캔버스랩 STAGE:ZERO 생산 라인에서 화장품을 만드는 리듬·주문 게임. `index.html`을 브라우저로 열면 바로 플레이(모바일 세로 화면 기준).

- 주인공: 화장품 회사 캔버스랩 마케팅팀 인턴 **험쮜** (면접 → 입사 → 2년, 3막 구조)
- **3막 구조** (24개월, 30·60·30일 비율)
  - 1막 론칭 준비(1년차 3~8월): 라인에서 시제품 주문서를 얼마나 정확하게 만드느냐에 따라 체크리스트 부품이 채워지고, 8월 말 연기 없이 론칭. 론칭 완성도 = 체크리스트 50% + 제품력·화제성·평판. 60% 미만 부품은 론칭 첫 주에 구멍(펌프 불량·배송 지연·심의 경고·상세페이지 미완성 등)으로 돌아온다
  - 2막 매출 만들기(9월~이듬해 8월): 매달 매출 목표 미션. 월 매출 = 론칭 완성도(점점 빠짐) + 화제성 + 평판 + 그달 회사일 + 쌓인 판로. 그달 회사일의 30%는 판로로 남는다. 브랜드 시트에 월 매출 그래프
  - 3막 해외 진출(2년차 9월~): 첫 나라 선택(미국 아마존·일본 큐텐·동남아 쇼피), 해외 진척으로 나라가 하나씩 열리고 열릴 때마다 매출 배수 상승. 라스베이거스 박람회
  - 브랜드 점수 = 론칭 완성도 30% + 월 최고 매출 40% + 해외 진출 30% → 엔딩·어워즈·CEO 조건
- **회사 자금·손익** (론칭 후, 자동): 론칭 때 회사 자금 1.5억. 월말에 손익(매출 − 원가 30% − 채널 수수료 10% − 광고비 − 고정비)이 회사 자금에 반영. 브랜드 점수에 누적 이익 20% 반영, 회사 자금이 마이너스면 스트레스·부도 위험
- **생산 라인 게임**(한 달 = 근무 1번): 험쮜는 STAGE:ZERO 1라인 담당. 메인 화면은 생산 라인
  - 근무 전: 「📋 이번 달 주문서」 3장 확인 → 「🤝 도우미」 동료 한 명 부르기(♥+3) → ▶ 근무 시작. ☕ 사무실(대화·간식)과 🧾 브랜드 시트로 갈 수 있음
  - 근무: 벨트로 빈 병이 흘러온다. 병 위 색 꼬리표 = 주문서 번호. 주문서대로 💛크림/💙젤 충진 → ⭕뚜껑 → 🏷️라벨(🚫🏷️ 라벨 없는 주문도 있음). 병이 기계 아래 칸에 들어왔을 때 버튼, 노란 선에 가까울수록 PERFECT, 이어 가면 콤보. 제형 틀림·빈 병에 뚜껑·순서 틀림·놓침은 불량. 3·2·1 카운트다운, 키보드 1·2·3·4도 됨
  - 막마다: 1막 주문서 = 론칭 부품 시제품(소비자 조사 샘플·제형 시제품·용기 테스트…) → 그 부품 진척(카테고리 전엔 다른 부품 50%까지). 2막 = 올리브영·자사몰·라이브커머스 등 국내 주문 → 매출, 주문이 섞여 들어옴. 3막 = 해외 주문(국기) 섞임 → 해외 진출. 벨트도 점점 빨라짐
  - 결과: 정확도로 S/A/B/C 등급, 평판(90%↑ +2), PERFECT → 제품력, 최대 콤보 → 화제성
  - 도우미 9명: SCM 벨트 속도 −15% · 경영지원 불량 3개 회수 · BM 라벨 자동 · 마케팅 PERFECT 판정 넓게 · PR 콤보 화제성 ×2 · 이커머스 주문마다 +2개 · 영업 매출 +15% · 사업부장 평판 +2·매출 +5% · 기획부장 병에 크림/젤 힌트
  - 업무 보드·경영기획 회의·험쮜 스케줄은 없앰. 승진은 평판·론칭·매출·해외·브랜드·♥로
  - 자동 플레이 30판 기준: 정확도 90% → 대부분 CEO, 72% → 팀장·이사, 50% → 사원·주임
- **같은 세상 비율**: 부서 소개·대화창 캐릭터는 `assets/b_*.webp`를 쓴다. 얼굴은 원래 그림 그대로 두고 몸 길이만 늘이거나 줄여 머리:몸 비율을 맞춘 그림(얼굴 폭 단위 키: 여자 185 · 남자 205). 화면에서도 같은 자로 그려서 얼굴 크기가 같고 남자가 더 크다
- **생산 라인 속도**: 주문당 6~7개, 벨트 속도·병 간격을 느긋하게(1막 2.3초 간격). 대신 병 하나당 성과를 올려 균형 유지
- **캐릭터 구별**: 이름 앞에 담당 업무 표기(대화창 「PR · 박서휘 대리」, 사무실 명패 「PR · 서휘」, 도우미 카드·관계도 업무 배지)
- **사무실 화면**(라인에서 ☕ 버튼, 대화·간식 전용): 세로 한 화면 사무실. 남색 헤더, 카펫 타일 바닥, 창문과 로고 벽, 유리 파티션 부장실, 흰 책상·모니터. 창가(위)일수록 높은 자리, 자리에는 직무 표기
  - 동료를 터치하면 험쮜가 걸어가 말주머니로 질문, 답을 고르면 A/B/C 평가(정답이면 론칭 체크·매출·해외 진척·♥↑, 영업 주임은 설렘도). 한 달 3번, 질문 60개는 한 번씩만
  - 🔥 열받은 동료(한 달 0~1명): 맞는 간식을 사다 주면 열이 식고 ♥↑. 못 식히면 월말 ♥-2
  - 바닥을 터치하면 험쮜가 걸어간다(2D 치비 걷기 움짤)
- 미션: 매달 상사·선배가 주는 미션(1막 부품, 2막 매출 목표, 3막 해외 진출). 성공하면 평판·성과급·♥
- 연말: 1년차는 연말정산 퀴즈 + 「막내 장기자랑」, 2년차는 자동 연말정산 + 「시크릿 산타」 + 「K-뷰티 어워즈」(브랜드 점수로 수상 결정, 수상 소감 선택)
- 커피 사 가기: 설렘 단계(어색·썸·연인)에 따라 그림과 대사가 달라짐
- **홈 화면 앱 · 비행기 모드**: 사파리에서 https://3678132-rgb.github.io/humzzwi-maker/ 열기 → 공유 → 홈 화면에 추가. 처음 한 번 온라인에서 열면 그림·글꼴 223개를 받아 두고(「오프라인 준비 완료」 표시), 그 뒤로는 비행기 모드에서도 실행. 새 버전은 온라인일 때 받아 두었다가 타이틀 화면에서 적용
- **빌드 코드**: 타이틀·메뉴 아래 「빌드 2026.10.09-xxxxxx」(날짜-파일 해시). 고친 뒤 `python3 tools/build.py`를 돌리면 빌드 코드와 오프라인 목록(`sw.js`)이 새로 만들어진다. `sw.js`는 직접 고치지 말고 `tools/sw.template.js`를 고칠 것
- 글꼴(주아·고운돋움)은 `fonts/`에 게임에 쓰는 글자만 담은 woff2로 같이 들고 다님(구글 폰트 불러오기 없음)
- 폰 화면 맞춤: 폰에서는 390×700 기준 화면을 기기 화면에 맞춰 통째로 확대·축소(Claude 앱 안처럼 세로가 짧아도 겹치지 않음), PC에서는 폰 프레임
- 저장 슬롯 4개: 새로 시작할 때 슬롯 선택, 불러오기·메뉴 「저장하기」에서 슬롯 선택, 진행 중인 슬롯에 매달 자동 저장. 덮어쓰기·지우기는 한 번 더 눌러야 실행(예전 단일 저장은 1번 슬롯으로 자동 이동)

## 에셋 (`assets/`)
- `sc_*` 장소 장면, `s_*`·`m_*` 험쮜 포즈, `ev_*` 이벤트 장면, `v_short*` 숏폼 움짤 2프레임: 힉스필드 험쮜 Soul로 생성
- `c_<행동>`·`c_<행동>_b`: 행동별 장면 2장(험쮜 Soul로 첫 장, 같은 장면에서 동작만 바꾼 둘째 장은 이미지 편집으로 생성)
- `a_*` 등장인물: 동료 8명 + 영업팀 다람 주임(가상)은 애니메이션 치비 스타일, 부엉 연구원·곰 사장님·여우 팀장은 동물 캐릭터
- `a_daram_f`·`f_daram_f`: 여성 다람 주임, `d_<장면>_m|f`: 데이트 장면(다람 남/여)
- 대표 캐릭터는 등장하지 않음(상사는 사업부장·기획부장 두 명, 비서실은 두 부장님 일정·회의 담당)
